## Overview

An IoT-based system for monitoring waste bins, built with a Spring Boot back end, a React front end, and PostgreSQL for storage.

## Key Features

- Real-time tracking of bin fill levels from IoT sensor data
- Route optimization for waste collection based on fill levels
- Spring Boot REST API backed by PostgreSQL
- React dashboard for monitoring bins and collection routes
