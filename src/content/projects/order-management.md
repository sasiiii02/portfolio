## Overview

A MERN Stack platform for food businesses to manage orders and deliveries, with a separate Admin flow for managing incoming orders and a Customer flow for placing and tracking them. Orders move through multiple stages and update in real time as their status changes.

## Key Features

- Admin flow for managing incoming orders and delivery status
- Customer-facing flow for placing and tracking orders
- Multi-stage order tracking (e.g. placed, preparing, out for delivery, delivered)
- Real-time status updates as an order moves through each stage
- REST API backing both the admin and customer clients
