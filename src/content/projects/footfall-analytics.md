## Overview

Built at TS Technologies. I led the migration of a legacy analytics dashboard to a React, TypeScript, and Vite architecture, rebuilding the entire frontend from scratch.

## Key Features

- Live branch, region, and sales analytics views fed by a real-time MQTT data layer
- Self-service reporting suite so teams generate their own reports
- Role-based access control with permission-scoped dashboards across multiple user roles
- Reusable, component-based UI system with centralized state management

## My Role

Owned the frontend end to end: architecture, the MQTT data layer, the reporting suite, and the RBAC layer.
