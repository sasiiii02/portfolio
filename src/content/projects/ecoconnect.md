## Overview

A React Native mobile app that connects users with eco-friendly products, nearby recycling points, and green initiatives, built with Expo, TypeScript, and Firebase.

## Key Features

- Directory of eco-friendly products
- Recycling point discovery
- Listings for green initiatives users can get involved with
- Firebase-backed data, with TypeScript throughout the app
